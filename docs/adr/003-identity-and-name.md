# ADR-003: Identity and name

**Status:** Accepted
**Date:** 2026-11-10

## Decision

| Item | Value |
|---|---|
| Name | Underplot Society (PT-BR: Sociedade da Tramoia; ES: Sociedad de la Tramoya) |
| Author | T.T.Ravenstone |
| Tagline | *Beneath the Surface.* |
| Colors | Obsidian `#111116`, Royal Purple `#5426A5`, Ancient Gold `#D9A441`, Ivory `#F5F3F7` |
| Typefaces | Space Grotesk (headings), Inter (body) |
| Symbol | A raven beneath a spinosaurus skull |

## Consequences

- The design tokens of the site are derived from these values.
- Every color combination used for text and interface elements must still meet WCAG 2.2 AA contrast; brand colors are adjusted with lighter or darker tints where they do not.
